# Project Instructions

## Project

This repository is my workspace for the FlyRank Frontend Development Track.

## Stack

- HTML
- CSS
- JavaScript
- React
- Vite
- Tailwind CSS
- Git and GitHub

## Development Conventions

- Use semantic HTML and accessible UI patterns.
- Prefer clean, readable, maintainable code.
- Use responsive design principles.
- Use React components when building React applications.
- Use Tailwind CSS for styling when appropriate.
- Keep components focused and reusable.
- Avoid unnecessary dependencies.
- Do not expose API keys, secrets, or environment variables in source code.
- Use descriptive names for variables, functions, and components.
- Follow Conventional Commits for Git commit messages.

## AI Assistance

- Explain significant changes before making them when clarification is useful.
- Do not make unnecessary changes outside the requested task.
- Preserve existing functionality unless a change is intentional.
- Point out potential accessibility, performance, security, or maintainability issues.
